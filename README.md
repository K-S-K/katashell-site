# Kata Shell — downloads

Downloads for Kata Shell, a file manager for macOS. The website is <https://katashell.app>.

This repository holds only the release files, under
[Releases](https://github.com/K-S-K/katashell-site/releases). Until 2026-10-23 it also held the
website and its update feed; both now live elsewhere, and their history is kept here.
